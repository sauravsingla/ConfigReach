Configuration coverage, measured deterministically.

High code coverage does not guarantee high configuration coverage. ConfigReach finds runtime configuration inputs, values, branches and important combinations, then maps them to test evidence without an LLM, GPU, API key or hosted service.

Quick start

Install locally and scan.

ConfigReach v0.9.4 source supports Python 3.10–3.14. Python 3.11+ uses the standard library at runtime; Python 3.10 adds only the pinned tomli TOML backport.

configreach — local CLI
$ python -m pip install --upgrade configreach
$ configreach scan .
$ configreach coverage .
$ configreach matrix .
$ configreach diff origin/main...HEAD
